# Lightroom third-party components

The original LopeOS application and processing code use the repository's existing React/Vite/Lucide stack. No Adobe executable code, proprietary profiles, marks or reference screenshots are served as product assets.

- `libraw-wasm` **1.6.0**, wrapper by ybouane and contributors, declares ISC for its wrapper. [Versioned source, wrapper and build instructions](https://github.com/ybouane/LibRaw-Wasm/tree/v1.6.0). Its [build script](https://github.com/ybouane/LibRaw-Wasm/blob/v1.6.0/compileLibraw.sh) pins **LibRaw 0.22.1** and **Little CMS 2.19.1** and uses Emscripten JPEG/PNG/zlib ports. The wrapper license does not replace the compiled libraries' licenses.
- **LibRaw** is available under LGPL 2.1 or CDDL 1.0. [Pinned source and license texts](https://github.com/LibRaw/LibRaw/tree/0.22.1). The unchanged compiled decoder is a separate WASM payload; source/build pins and the installed payload checksum are recorded in `engine-manifest.json`. Distributions of this payload must retain the corresponding LibRaw notices and the applicable source/relinking provisions.
- **Little CMS**, Marti Maria and contributors, MIT. [Pinned source and COPYING](https://github.com/mm2/Little-CMS/tree/lcms2.19.1). Emscripten port components retain their own libjpeg/libpng/zlib notices in the corresponding toolchain/source distribution. The exact Emscripten port revisions are not exposed in the npm package; do not infer them from the wrapper version.
- `ag-psd` **31.0.3**, Agamnentzar and contributors, MIT, reused from the existing Image Editor. [Source and license](https://github.com/Agamnentzar/ag-psd). Only compatible RGB/8 composites are developed; PSD/PSB layer-editing parity is not implied.
- **FFDNet Color (clipped)**, Kai Zhang and contributors, MIT. Official [KAIR architecture source](https://github.com/cszn/KAIR/blob/fc1732f4a4514e42ce15e5b3a1e18c828af47a1e/models/network_ffdnet.py) and [v1.0 checkpoint](https://github.com/cszn/KAIR/releases/download/v1.0/ffdnet_color_clip.pth). The optional ONNX graph uses unchanged official learned weights. The bundled [MIT notice](../../public/models/denoise/LICENSE-FFDNet.txt), [model manifest](denoise-model-manifest.json) and `scripts/export-denoise-model.py` retain provenance, hashes and reproducible conversion instructions. This model is independent of Adobe.
- **ONNX Runtime Web 1.31.1**, Microsoft Corporation and contributors, MIT. [Versioned source](https://github.com/microsoft/onnxruntime/tree/v1.31.1), [upstream license](https://github.com/microsoft/onnxruntime/blob/v1.31.1/LICENSE), and [bundled notice](../../public/models/denoise/engine/LICENSE-ONNX-Runtime.txt). Only the CPU WASM runtime, loader and self-contained JavaScript bundle are served for optional installation. Exact byte counts and SHA-256 hashes are in [the runtime package manifest](../../public/models/denoise/engine/manifest.json).
- The four photographic samples are by **Jon Sullivan**, released into the public domain. Exact primary file pages, unchanged filenames/dimensions, SHA-256 values and permission evidence are in `public/photos/credits.json`. These may be used as test/demo fixtures independently of private user photos.
- The generated sRGB/linear-sRGB matrix/TRC profiles are original code-generated profiles using public sRGB/D50 constants. They do not copy an operating-system or Adobe profile file. Pillow/LittleCMS verification accepts the generated profiles and transforms.

Adobe documentation images under `docs/lightroom/reference/` are retained only for authorized private reference comparison, outside `public/` and the application bundle. Adobe retains their rights. Existing PerfectHue desktop attribution is preserved and never inserted into photographic exports.
