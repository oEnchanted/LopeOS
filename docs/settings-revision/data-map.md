## Enforcement boundaries

**Full reset (November 13, 2026):** Settings → General → Reset LopeOS clears `lope.*` localStorage/sessionStorage, LopeOS IndexedDB databases (including recovery drafts and imported photos), `lope.*` / `lope-*` caches, and the three WebLLM asset caches. This is broader than preference reset or history/cache clearing described above. Remote workspace files, remote Browser profiles, browser permissions, and unrelated origin data remain. `packages/sdk/src/reset.ts` owns the deletion boundary. A persisted request, a clean document restart, and Web Locks coordinate tabs before erasure; stale tabs only clear their own session after another tab has completed. The request is removed only after all deletion stages succeed. `tests/setup/reset.test.ts` and `tests/setup/reset.spec.ts` verify deletion, preservation, retry, and the return to setup using isolated storage.

The browser owns website permissions. LopeOS switches stop its implemented preview/test/location operations and gate future requests; they do not revoke browser permissions. Per-app file policy wraps every shared FileService operation and its subscription, as well as shared file dialogs/open calls. Direct Terminal and remote Chromium services have their own authentication. Same-origin code is not isolated by these toggles.

The privacy screen obscures the workspace and stops preview capture; it does not authenticate a person, encrypt files, sign out, or guarantee that remote processes stop. Settings explicitly states these limits. No global OS networking, hardware, password-vault, screen-reader, or shutdown controls are offered.
