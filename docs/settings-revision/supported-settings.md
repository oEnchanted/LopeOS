# Settings behavior and boundaries

All pages use the same versioned preference store. Changes take effect in open shared UI immediately and persist in this browser when storage is available. **Session only** identifies storage failure. **Reset preferences** changes shared preferences; it does not erase documents, wallpaper uploads, or histories. Imported preferences are validated and previewed before application.

**General → Reset LopeOS** is the separate full reset. After an explicit **Erase and restart** confirmation, it removes every local LopeOS account, preferences, histories, wallpaper uploads, imported photos, recovery drafts, and downloaded model caches in this browser. Unsaved work is lost. Remote workspace files and unrelated browser data remain. Open LopeOS tabs restart into a black screen with the white LopeOS mark and progress bar, then fade into fresh Setup Assistant. Reduced motion removes the fade. A failed erase stays on the boot screen with **Try again**; the pending request survives reload until cleanup succeeds.

| Category | Implemented behavior | Conditional features and scope |
|---|---|---|
| General | Actual package version/build, published-build check, local storage estimate, region/date/clock formatting, startup apps, window restoration, preference export/import/reset, full local reset to Setup Assistant | Update check uses the LopeOS build endpoint. It is not an OS update. English is the bundled interface language; remote storage quota is not invented. |
| Appearance | Light/Dark/System, live optical preview, glass clarity, accent/selection/folder colors, four rendered icon styles, sidebar icon size, wallpaper tinting | Reduced transparency overrides glass. Personal images use the accent as their tint fallback. Editing surfaces retain their application style. |
| Desktop & Dock | Icon size/magnification, three positions, auto-hide with keyboard/touch reveal, opening/minimizing animation, running markers, recent apps, minimize destinations, title-bar action, desktop items, Show Desktop | Windows remain mounted when minimized; Show Desktop can restore them. No unimplemented window-group or virtual-desktop controls. |
| Display & Scale | Shared interface scale, shared text size, row density, effects quality, fullscreen, sizing reset | Browser fullscreen is feature-detected and user-initiated. Interface scale changes the virtual work area; it does not change document zoom. |
| Menu Bar | Visibility, material strength, status visibility/order, date/clock options and recent-item count | Runtime health is a workspace connection indicator, not host Wi-Fi. Capture indicators remain available while chrome is hidden. |
| Search | Apps, active commands, permitted workspace filenames/folders, root scope and exclusions, retention/clear, shortcut choice | Filesystem requests use the authenticated service after two typed characters, bounded to 40 folders and 50 results. No external suggestion provider is configured or called. |
| Wallpaper | Approved PerfectHue light/dark originals, original LopeOS art, personal upload/removal, fill/fit/center, timed rotation, exact creator credit | Upload limited to supported image MIME types and 2 MB for local persistence. No dynamic-wallpaper or virtual-desktop claim. PerfectHue originals are local assets; permission provenance is recorded. |
| Notifications & Focus | App-specific alerts/badges/sounds, preview policy, history retention/clear, DND, manual presentation mode, test alerts | Browser notifications have a separate explicit permission request. DND controls LopeOS only. LopeOS capture suppresses previews; host screen sharing cannot be detected reliably. |
| Sound | LopeOS mute/volume, alert sound/volume/preview, interface sounds, explicit microphone test, level meter and stop | Device selection is offered only when the browser implements it. Input enumeration follows consent. Output uses selectAudioOutput/setSinkId where present. Other applications are unaffected. |
| Accessibility | Motion/transparency/contrast preferences, non-color indicators, shared text size, keyboard focus, hover/focus text, explicit read-aloud, native media caption preference | Read-aloud uses available local browser voices. Captions apply to media with existing caption tracks. Host screen-reader guidance replaces a fake system switch. No speech recognition or generated-caption service is claimed. |
| Session & Privacy Screen | Inactivity deadline, hide-when-backgrounded behavior, preview suppression, visual cover, safe reload/close-all | Cover stops local capture and traps focus; it is not account authentication or encryption. All registered unsaved-work guards run before closing applications. Remote processes can outlive their UI. |
| Privacy & Security | Browser permission states/guidance, LopeOS capability gates, capture tests and Stop controls, clipboard retention/review/clear, local diagnostics, data export/removal, service disclosures | Browser owns website permission revocation. Feature disable stops current/pending local use. File policies gate the shared API; same-origin app code is not a security sandbox. Deletions have explicit scope and confirmations. |
| Profile & Accounts | Browser-local display name, actual runtime identity when available, connection status and links to session controls | No connected account sign-in/passkey/session-list API exists here. Visitor deployments may assign identities via service-issued cookies; no fabricated OS accounts. |
| Weather | City search/manual choice, explicit optional location, shared units/location, automatic refresh preference, provider attribution | Coordinates/search go to Open-Meteo. Permission disable/unmount stops geolocation. Manual location remains usable without it. |
| Applications | Registered default apps/associations, per-app future-launch gates, enforced shared workspace API access, startup shortcut | File policies do not revoke direct Terminal/Chromium service credentials. Existing windows are not forcibly destroyed by disabling future launches. |

Implementation is primarily in `apps/web/src/apps/settings`, `apps/web/src/shell/{appearance,materials,system,SystemControls,SearchPanel,DesktopExtras,filePolicy,Shell,WindowFrame}`, `packages/ui/src/settings.tsx`, and the contracts/SDK preference modules. Weather’s location and refresh integration uses the same store and managed capability lifecycle.

Word and Image Editor internal components were not restyled. The shell supplies their outer frame, Dock icon, and shared service context. Their recovery stores remain separate from preference reset and normal history/cache clearing.
